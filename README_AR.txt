نسخة مبادرة جاهزة للنشر على GitHub + Vercel

الملفات:
- index.html : التطبيق
- version.json : رقم إصدار التطبيق وفحص التحديثات

طريقة النشر:
1) أنشئ Repository جديدًا مستقلًا لهذا التطبيق في GitHub.
2) ارفع index.html و version.json إلى الفرع main.
3) اربط المستودع الجديد بمشروع Vercel جديد.
4) استخدم رابط Vercel الناتج للمستخدمين.

عند إصدار تحديث لاحقًا:
- نرفع نسخة index.html الجديدة.
- نرفع version.json برقم إصدار أعلى، مثل 1.0.1.
- بعد نشر Vercel، سيكتشف المستخدمون النسخة الجديدة ويظهر لهم زر «تحديث الآن».

ملاحظة: بيانات Excel الحالية في التطبيق مخزنة محليًا على جهاز كل مستخدم. هذا الإعداد يوحّد تحديث البرنامج، لكنه لا يجعل البيانات مشتركة بين جميع المستخدمين.
